Engineering Trade-Off Visualizer

HTML, CSS and JavaScript • v2.0

What It Is

A web version of my trade-off simulator. You move sliders for speed, torque and cost, split 100 points between them, and the score and chart update as you go.

Why I Made It

The Python version makes you type everything in and only shows the result at the end. I wanted to see the score change while I moved things around.

What It Does

  • Sliders for speed, torque and cost
  • Priority points that have to add up to 100 (decimals like 33.4 work)
  • A score out of 100 that matches the Python version
  • A chart of how much each factor adds to or takes away from the total
  • Saving designs and ranking them by score

What Changed in v2.0

The scoring now matches the Python version, so the same design gets the same score in both. The chart used to just repeat the slider values, and now it shows why a design scored the way it did. I also fixed a bug where 33.4 + 33.3 + 33.3 got rejected, since JavaScript adds it up to 99.99999999999999, and made the chart fit on phones.

Built With

Plain HTML, CSS and JavaScript, with the chart drawn on a canvas. It's hosted on GitHub Pages.
